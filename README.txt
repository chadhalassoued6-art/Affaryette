Afariyet — prototype statique HTML/CSS

Fichiers :
- index.html : accueil
- produits.html : catalogue et maquettes des fonctionnalités du BMC
- blog.html : conseils de seconde main
- a-propos.html : mission et valeurs
- contact.html : formulaire de démonstration
- css/style.css : styles partagés et responsive
- images/ : dossier réservé aux images locales

Pour ouvrir :
1. Extraire Afariyet.zip.
2. Ouvrir index.html dans un navigateur.
3. Utiliser le menu pour naviguer entre les pages.

Limites :
Le projet utilise uniquement HTML et CSS. Recherche, filtres, panier, QR de paiement, IA et recommandations ne sont pas réellement interactifs. Le formulaire de contact n'envoie aucun message. Les éléments sont des maquettes de présentation.
